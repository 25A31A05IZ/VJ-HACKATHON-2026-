🌱 AgriSmart AI

AI-Based Smart Agriculture and Crop Optimization

AgriSmart AI is an AI-powered agriculture project developed for the VJ Hackathon. It aims to support farmers with smarter agricultural decisions and improve crop planning through technology.

Key Features

- Smart Crop Optimization
- AI-Based Agricultural Support
- Data-Driven Farming Insights
- Sustainable Agriculture
